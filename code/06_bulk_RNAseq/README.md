# Bulk RNA-seq analysis

This folder contains scripts for bulk RNA-seq analysis of paired Normo-CAFs and Hypo-CAFs.

Analyses include principal component analysis, heatmap visualization, differential expression analysis, KEGG pathway analysis, Gene Ontology analysis, Hallmark gene set enrichment analysis, and oxygen switching analysis.

## Scripts

- `PCA_raw.R`: Principal component analysis of bulk RNA-seq samples.
- `DEGanalysis_new_raw.R`: Differential expression analysis and downstream gene set analyses.
