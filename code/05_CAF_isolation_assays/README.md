# CAF isolation assays

This folder contains scripts for analyses of CAF isolation, outgrowth, morphology, and proliferation assays.

Analyses include comparison of time to CAF outgrowth, cell aspect ratio, and proliferation curves between Normo-CAFs and Hypo-CAFs.

## Scripts

- `CAF_outgrowth_raw.R`: Analysis of time to CAF outgrowth under normoxic and hypoxic isolation conditions.
- `CAF_morphology_raw.R`: Analysis of CAF morphology and aspect ratio.
- `Proliferation_raw.R`: Analysis of proliferation assay data.
- `Proliferation_forFig_raw.R`: Figure-oriented script for proliferation assay visualization.
